Projects

Flutter · Android & iOS
Baguettering Kitchen Orders
Baguettering Catering Services · INCONS Professional Services LLP
In Production

A cross-platform Flutter mobile application that replicates Baguettering Catering Services' Frappe/ERPNext web portal — enabling kitchen staff to browse, create, and manage weekly meal orders entirely from their mobile devices. The app mirrors the website's full workflow: from placing draft orders to tracking status through Pending With Kitchen, Approved, and Preparing stages, with real-time data fetched live from ERPNext with no local database.

Secure Authentication
Session-based login with Flutter Secure Storage (iOS Keychain & Android Keystore). Dynamic CSRF token capture. Passwordless Email Link login via Frappe's send_login_link API.
Order Dashboard
4-status grid (Draft, Pending, Approved, Preparing) with live counts. Month/Year picker with client-side date filtering. Pull-to-refresh and empty state handling.
Change Password
In-app password change using update_password API with current + new + confirm fields. No email required — fully handled within the app.
Security Architecture
No hardcoded API credentials. HTTPS enforcement. Separate read/write headers for CSRF. Sanitized error messages — no raw server tracebacks shown to users.
Navigation Drawer
Side drawer with profile section, My Kitchen Orders, Make an Order, Reset Password, and Logout. ListTile-based for reliable tap detection.
API Integration
8 Frappe REST endpoints integrated. Owner + workflow_state filters. HttpLogger for structured request/response debugging in debug builds.
Stack: Flutter Dart Frappe REST API ERPNext Flutter Secure Storage app_links HTTP Android / iOS
